# L-System Generative Art Project (This assignment was done in Google Colab due to insufficient space in my laptop)

## Overview
This project implements an L-System to generate geometric fractal artwork. It uses Python and Matplotlib to interpret L-System strings into visual art.

## Setup & Installation
1. Connect to T4 GPU. (Find Connect button > Change runtime type > Select T4 GPU > Confirm)
2. Click on the Run all button
